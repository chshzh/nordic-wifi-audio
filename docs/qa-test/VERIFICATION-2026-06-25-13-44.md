### P1 — Compiler warnings (4 × `-Wunused-variable`)

```
src/audio/wifi_audio_rx.c:62   'num_thrown' defined but not used
src/audio/audio_system.c:123   'encoded_data_size' unused
src/audio/audio_system.c:128   'encoded_data' unused
src/audio/audio_system.c:130   'test_tone_finite_pos' unused
```

**Cause:** these variables are used only inside codec/Opus-gated `#if` paths. They were previously masked by `CONFIG_COMPILER_OPT="-Wno-unused-variable …"`, which was intentionally moved to `overlay-opus.conf` (so non-Opus builds no longer suppress them).
**Fix (Phase 3):** gate the declarations under the same `#if` as their use, or mark `__maybe_unused`. Benign at runtime; flagged only to keep the build warning-clean.
